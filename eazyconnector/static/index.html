Importing

    
The ⇩ button imports connections from ~/.ssh/config or Ásbrú.
    You get a preview — grouped, with jump-host links resolved and any missing key files
    flagged — before anything is created. Only structure and key-file paths are read; saved
    passwords are never touched. Re-importing skips anything already present.

Jump hosts

    
Add the bastion as its own connection, then set it as the Jump host of the
    target. Chains work: the jump host may have a jump host of its own. Host keys are
    verified at every hop.

  


  

    
Port forwarding

    
One rule per line in the connection editor. They start with the session and stop
    when its pane closes.

    
L 8080:localhost:80     local 8080  → localhost:80 on the server
R 9090:localhost:22     server's 9090 → localhost:22 on your machine
D 1080                  SOCKS5 proxy on local 1080

    
Local and SOCKS listeners bind 127.0.0.1 only, never 0.0.0.0.

  


  

    
VPN (one click, password + TOTP automatic)

    
Add a profile with + next to VPN, pick your .ovpn file, and fill in the
    username, password and the TOTP secret (the base32 string from when you set up your
    authenticator — not the 6-digit code). Then connect is one click: the code is
    generated and answered for you.

    

      
Second factorauto-detected — static-challenge in the
        .ovpn means SCRV1, otherwise the code is appended to the password. Override it if needed.

      
Expired codeif the server re-challenges, a fresh code is sent automatically

      
☰ buttonshows the openvpn log for this profile

      
rootopenvpn needs it. Store your sudo password in the profile, or set up
        sudoers. Nothing is cached anywhere else.

    

    
The .ovpn (private key included) lives encrypted in the vault. It is written to
    ~/.eazyconnector/run/ at 0600 only while connected, and deleted on disconnect.

  


  

    
Security

    
    
      
  • Passwords, private keys and passphrases live encrypted in
        ~/.eazyconnector/vault.enc. Hostnames and ports sit in plain
        config.json — never any secret.
    • 
      
  • Secrets never reach the browser. The page asks to connect; the server authenticates.
    • 
      
  • The vault auto-locks after 15 minutes idle. Open sessions keep running.
    • 
      
  • Change the master password any time with the button by Lock vault — the vault is
        re-encrypted and the old password stops working.
    • 
      
  • Unknown SSH host keys ask before trusting. Verify the fingerprint out-of-band
        (ssh-keyscan -t rsa HOST | ssh-keygen -lf -) before accepting.
    • 
      
  • The server listens on 127.0.0.1 only, and the URL token is in the fragment,
        so it never reaches the server logs.
